🌌 Neon Aura AR

Advanced Hand Tracking + Interactive Visual Experience (Web AR)

📖 Overview

Neon Aura AR ek browser-based Augmented Reality experience hai jo real-time hand tracking use karke interactive neon visuals aur sound effects generate karta hai.

User apne haath se gestures perform karta hai aur system instantly usko particles, lightning, glow effects, aur audio feedback me convert karta hai.

✨ No external app needed — runs directly in your browser.

🧠 Tech Stack
Frontend: HTML, CSS, JavaScript
Hand Tracking: MediaPipe Hands
Rendering: HTML5 Canvas API
Audio: Web Audio API
Camera: Browser MediaDevices API
